# Endless runner game built using pygame

Climate Change is one of most challenging issues that we face today. It is affecting our
planet in numerous harmful ways, leading to global warming, rising sea levels, floods,
wildfires, and other devastating consequences. Human activities that release
greenhouse gases, such as carbon dioxide and methane into the atmosphere are the
main causes of climate change.

The first crucial step in combating climate change is raising awareness and educating
people about its causes and the actions required to address it. Students of today are the
leaders and decision-makers of tomorrow. Teaching students about climate change and
its impacts can inspire meaningful initiatives to address this serious issue.

Studies have shown that video games can serve as an effective tool for education and
for promoting positive behavioral changes. This engineering project aims to increase
climate change awareness and motivate positive behavioral changes in students that
can help fight climate change.

This educational and fun game aims to raise awareness about climate change, and encourages positive behavior change to adopt
eco-friendly activities. Players navigate through levels where they avoid pollution obstacles and collect green items
to reduce their carbon footprint.

## Steps for installation and running the game
- Clone this repository
- Install Python 3.x version
- Install the required libraries using the requirements.txt file

```
pip install -r requirements.txt
```
- Launch the game with:
```
python CarbonChallenge.py
```
